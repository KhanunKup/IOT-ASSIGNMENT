Raspberry Pi 4 SHT31 (Temp & Humidity) I2C1: SDA=GPIO2 (Pin 3), SCL=GPIO3 (Pin 5), 0x44
Raspberry Pi 4 Ultrasonic HC-SR04 TRIG=GPIO23 (Pin 16), ECHO=GPIO24 (Pin 18)

Arduino UNO R4 LoRa Node LED (Downlink) Digital Pin D4 (ผ่านตัวต้านทาน 220Ω ลง GND)

SSE URL: http://localhost:3000/sse
HTTP JSON-RPC URL: http://localhost:3000/mcp
4 MCP Tools ที่พร้อมให้ AI Chat box เรียกใช้งาน:
  • 1. read_pi_sensors — อ่านค่า SHT31, Ultrasonic HC-SR04, และสถานะ LED
  • 2. control_pi_devices — สั่งเปิด/ปิดไฟ LED บน Raspberry Pi (GPIO 17)
  • 3. read_from_mqtt — อ่านค่าแสง (LDR A0) และ Infrared (D3) จาก LoRa Node
  • 4. publish_to_mqtt — ส่งคำสั่งเปิด/ปิดไฟไปที่ LoRa Node (Pin D4) หรือ MQTT
