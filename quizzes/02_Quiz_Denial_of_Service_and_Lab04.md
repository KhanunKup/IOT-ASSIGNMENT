### ข้อที่ 1
ตามมาตรฐาน NIST Computer Security Incident Handling Guide นิยามของ **Denial-of-Service (DoS)** คือข้อใด?
A. การขโมยรหัสผ่านของผู้ดูแลระบบผ่านโปรโตคอล Telnet  
B. การกระทำที่ขัดขวางหรือลดทอนความสามารถในการใช้งานเครือข่าย ระบบ หรือแอปพลิเคชัน โดยการทำให้ทรัพยากรหมดสิ้นไป (Exhausting resources) เช่น CPU, หน่วยความจำ, แบนด์วิดท์ หรือพื้นที่ดิสก์  
C. การปลอมแปลงหน้าเว็บเพจเพื่อหลอกเก็บข้อมูลบัตรเครดิต

### ข้อที่ 2
การโจมตีแบบ **SYN Spoofing Attack** ส่งผลกระทบต่อตารางโครงสร้างข้อมูลใดของระบบปฏิบัติการเซิร์ฟเวอร์เป้าหมาย?
A. Routing Table  
B. ARP Cache Table  
C. Connection Backlog Table (Half-open connection queue)  
D. DNS Cache Table  
**เฉลย: C**  
**คำอธิบาย:** เมื่อเซิร์ฟเวอร์ได้รับแพ็กเก็ต TCP SYN ที่มี IP ต้นทางปลอม เซิร์ฟเวอร์จะตอบ SYN-ACK และจัดสรรหน่วยความจำใน Backlog Queue เพื่อรอ ACK สุดท้าย แต่เนื่องจากไม่ได้รับ ACK คิวจึงเต็ม (Queue Exhaustion) ทำให้ปฏิเสธการเชื่อมต่อใหม่จากผู้ใช้จริง

### ข้อที่ 3
เทคนิคใดที่ใช้แก้ไขปัญหา SYN Spoofing โดย**ไม่ต้องจัดสรรหน่วยความจำ (State Memory)** ใน Backlog Queue เมื่อได้รับ SYN packet แต่จะเข้ารหัสข้อมูล Session เก็บไว้ในฟิลด์ Initial Sequence Number (ISN) ของแพ็กเก็ต SYN-ACK แทน?
A. Ingress Filtering  
B. SYN Cookies  
C. Reverse DNS Lookup  
D. Port Knocking  
**เฉลย: B**  
**คำอธิบาย:** SYN Cookies ทำงานโดยการคำนวณ Cryptographic Hash จาก IP/Port ต้นทาง-ปลายทาง และค่าลับของเซิร์ฟเวอร์ แล้วนำไปใส่เป็นค่า Initial Sequence Number (ISN) ในแพ็กเก็ต SYN-ACK เมื่อไคลเอนต์ตอบ ACK กลับมา เซิร์ฟเวอร์จะแกะ ISN-1 เพื่อตรวจความถูกต้องและเปิด Session ทันทีโดยไม่ต้องจองหน่วยความจำล่วงหน้า

### ข้อที่ 4
ในการโจมตีแบบ **DNS Amplification Attack** ปัจจัยสำคัญ 2 ประการที่ทำให้ผู้โจมตีสามารถขยายขนาดทราฟฟิก (Amplification Factor) ให้มีขนาดใหญ่กว่าคำขอได้หลายสิบเท่าคืออะไร?
A. การใช้โพรโทคอล TCP และคำขอแบบ HTTP GET  
B. การใช้โพรโทคอล UDP (ไม่มี Handshake ทำให้ปลอม IP ต้นทางได้ง่าย) ร่วมกับคำขอประเภท `ANY` query หรือฟีเจอร์ EDNS0  
C. การขโมย Private Key ของเซิร์ฟเวอร์ DNS  
D. การส่งคำสั่ง Ping ขนาดใหญ่ (Ping of Death)  
**เฉลย: B**  
**คำอธิบาย:** DNS ใช้ UDP ทำให้สามารถปลอม IP แหล่งกำเนิดเป็น IP ของเหยื่อได้ง่าย และเมื่อส่งคำขอขนาดเล็ก (เช่น 60 ไบต์) พร้อมขอแบบ `ANY` query หรือเปิดใช้ EDNS0 เซิร์ฟเวอร์ DNS แบบ Open Resolver จะตอบกลับแพ็กเก็ตขนาดใหญ่ถึง 3,000-4,000 ไบต์กลับไปยังเหยื่อ

A. Ping of Death

### ข้อที่ 16
เมื่อเกิด ICMP Flood บนลิงก์เครือข่าย ผลกระทบที่เกิดขึ้นกับ **UDP Traffic** และ **TCP Traffic** ของผู้ใช้งานปกติ มีความแตกต่างกันอย่างไรในเชิงพฤติกรรมการทำงาน?
A. UDP จะส่งซ้ำแพ็กเก็ตอัตโนมัติ ส่วน TCP จะทิ้งข้อมูลทันที

**คำอธิบาย:** คำสั่งในชุด `iproute2` บน Linux สำหรับลบ default gateway คือ `ip route del default` (หรือ `route del default` ในคำสั่งแบบดั้งเดิม)

### ข้อที่ 20
คำสั่งใดของ **hping3** ที่ใช้ส่งแพ็กเก็ตแบบ UDP Flood ไปยังพอร์ต 53 ของเครื่องเป้าหมาย 192.168.1.50?
A. `hping3 -2 -p 53 --flood 192.168.1.50`  
B. `hping3 --icmp -p 53 192.168.1.50`  
C. `hping3 -S -p 53 192.168.1.50`  
D. `hping3 --udp-flood -d 53 192.168.1.50`  
**เฉลย: A**  
**คำอธิบาย:** `-2` กำหนดโหมด UDP, `-p 53` กำหนดปลายทางพอร์ต 53, และ `--flood` คือยิงทราฟฟิกด้วยความเร็วสูงสุด
