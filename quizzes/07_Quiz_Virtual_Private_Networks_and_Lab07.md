### ข้อที่ 1
ตามมาตรฐาน **NIST SP 800-77** โพรโทคอล **IPsec (IP Security)** จัดเป็นกลไกควบคุมความมั่นคงปลอดภัยที่ทำงานในระดับเลเยอร์ใดของแบบจำลอง OSI Model?
A. Data Link Layer (Layer 2)  
B. Network Layer (Layer 3)  
C. Transport Layer (Layer 4)  
D. Application Layer (Layer 7)  
**เฉลย: B**  
**คำอธิบาย:** IPsec ทำงานที่ Network Layer (Layer 3) จึงมีความโปร่งใสต่อแอปพลิเคชัน (Application-independent) สามารถปกป้องทราฟฟิกข้อมูล IP ทั้งหมดที่วิ่งผ่านโดยที่ซอฟต์แวร์ระดับบนไม่ต้องแก้ไขโค้ด

### ข้อที่ 2
โพรโทคอลย่อยของ IPsec ในข้อใดที่ทำหน้าที่รักษาความลับของข้อมูลด้วยการเข้ารหัส (Confidentiality) พร้อมทั้งยืนยันความถูกต้องและความสมบูรณ์ของข้อมูล (Data Origin Authentication and Integrity)?
A. AH (Authentication Header)  
B. ESP (Encapsulating Security Payload)  
C. IKE (Internet Key Exchange)  
D. L2TP (Layer 2 Tunneling Protocol)  
**เฉลย: B**  
**คำอธิบาย:** 
- **AH (Protocol 51):** ให้บริการเฉพาะ Integrity และ Authentication แต่ **ไม่เข้ารหัสข้อมูล** (No Confidentiality)
- **ESP (Protocol 50):** ให้บริการทั้งการเข้ารหัสข้อมูล (Encryption/Confidentiality) และการตรวจสอบความถูกต้องของข้อมูล (Authentication/Integrity)

A. Transport Mode เข้ารหัสเฉพาะสายแลน ส่วน Tunnel Mode เข้ารหัส Wi-Fi

### ข้อที่ 9
ใน Lab 7-B มีการใช้คำสั่ง **tcpdump** บนเครื่อง Attacker ดังนี้:
```bash
tcpdump -n -A -i eth1
```
พารามิเตอร์ `-n` และ `-A` มีหน้าที่การทำงานอย่างไรตามลำดับ?
A. `-n` ไม่แปลงหมายเลข IP/Port เป็นชื่อโฮสต์ (ปิดการทำ Reverse DNS เพื่อความรวดเร็ว) และ `-A` ให้แสดงผลลัพธ์ข้อมูลเพย์โหลดของแพ็กเก็ตเป็นตัวอักษร ASCII  
B. `-n` รันในโหมดกลางคืน และ `-A` แสดงเฉพาะแพ็กเก็ต ARP  
C. `-n` ส่งเสียงแจ้งเตือน และ `-A` ย่อขนาดหน้าจอ  
D. `-n` ทำลายไฟล์ และ `-A` เพิ่มสิทธิ์ Root  
**เฉลย: A**  
**คำอธิบาย:** 
- `-n`: ห้ามแปลงที่อยู่ IP เป็นชื่อ Domain Name ช่วยให้ tcpdump ทำงานได้เร็วและไม่ส่งทราฟฟิก DNS เพิ่มขึ้นในเครือข่าย
- `-A`: แสดงเนื้อหา Packet Payload ในรูปแบบข้อความ ASCII ทำให้มองเห็นข้อความที่ไม่ได้เข้ารหัส เช่น รหัสผ่าน Telnet หรือข้อความแชตได้โดยตรง

ไดเรกทอรีมาตรฐานที่ระบบ OpenVPN บน Linux ใช้ในการจัดเก็บใบรับรองดิจิทัล (Digital Certificates) และกุญแจลับ (Private Keys) คือพาธใด?
A. `/etc/openvpn/` (หรือ `/etc/openvpn/server/` และ `/etc/openvpn/easy-rsa/pki/`)  
B. `/tmp/keys/`  
C. `/home/user/certs/`  
D. `/var/log/openvpn/`  
**เฉลย: A**  
**คำอธิบาย:** ไฟล์ใบรับรองและคีย์ เช่น `ca.crt`, `server.crt`, `server.key`, และ `dh.pem` (Diffie-Hellman parameters) จะถูกเก็บรักษาไว้ภายใต้ไดเรกทอรีความปลอดภัยสูง `/etc/openvpn/`

### ข้อที่ 17

A. `config router ospf` และ `config router bgp`  
B. `config vpn ipsec phase1-interface` และ `config vpn ipsec phase2-interface`

- Phase 1: `config vpn ipsec phase1-interface`
- Phase 2: `config vpn ipsec phase2-interface`

### ข้อที่ 18
จากข้อคิดเห็นในสไลด์ Week 14 หัวข้อ Design the Architecture มีข้อความระบุว่า: *"Routing policy is as important as firewall configuration"* เพราะเหตุใดการจัดการตาราง Routing จึงมีความสำคัญเทียบเท่ากับการคอนฟิกไฟร์วอลล์ในการทำ VPN?
A. เพราะหากไม่มีเราต์เตอร์ ไฟร์วอลล์จะเปิดเครื่องไม่ติด  
B. เพราะแม้ไฟร์วอลล์จะอนุญาตให้แพ็กเก็ตผ่าน แต่ถ้าไม่มีเส้นทาง (Route) ชี้ให้ทราฟฟิกไหลเข้าสู่อินเทอร์เฟซทันเนล (Tunnel Interface) หรือเครือข่ายภายในไม่รู้จักเส้นทางขากลับ แพ็กเก็ตก็จะไม่สามารถส่งผ่านเครือข่าย VPN ได้  
C. เพราะตาราง Routing เป็นตัวสร้างคีย์เข้ารหัส  
D. เพราะ Routing ช่วยประหยัดค่าไฟฟ้า  
**เฉลย: B**  
**คำอธิบาย:** การเซตอัป VPN ไม่ใช่แค่สร้างทันเนลแล้วเสร็จ แต่ระบบต้องการ Static Route หรือ Dynamic Routing เพื่อชี้ทางให้แพ็กเก็ตที่จะไปยังวงปลายทางถูกส่งเข้าสู่ Virtual Tunnel Interface เสมอ

### ข้อที่ 19
ในโพรโทคอล IKE การเจรจา Phase 1 มีโหมดการทำงาน 2 โหมด คือ **Main Mode** และ **Aggressive Mode** ข้อใดคือความแตกต่างสำคัญระหว่าง 2 โหมดนี้?
A. Main Mode ส่ง 2 แพ็กเก็ต ส่วน Aggressive Mode ส่ง 10 แพ็กเก็ต  
B. Main Mode มีการแลกเปลี่ยนข้อความ 6 แพ็กเก็ต และสามารถปกป้องตัวตน (Identity Protection) ของคู่สนทนาได้ ในขณะที่ Aggressive Mode แลกเปลี่ยนเพียง 3 แพ็กเก็ตเพื่อความรวดเร็วแต่ส่งข้อมูลระบุตัวตนในลักษณะที่ไม่ได้รับการปกป้อง  
C. Aggressive Mode ไม่ใช้คีย์ในการเข้ารหัส  
D. Main Mode ใช้กับระบบโทรศัพท์เท่านั้น  
**เฉลย: B**  
**คำอธิบาย:** Main Mode ปลอดภัยสูงกว่าเพราะแบ่งเป็น 3 คู่ (6 แพ็กเก็ต) โดย 2 แพ็กเก็ตสุดท้ายที่ระบุ ID ของเกตเวย์จะถูกเข้ารหัส ส่วน Aggressive Mode รวบเหลือ 3 แพ็กเก็ตเพื่อความเร็ว แต่แลกด้วยการไม่ปกป้อง Identity ของจุดเชื่อมต่อ

### ข้อที่ 20
ข้อใดเป็นเหตุผลสำคัญที่ทำให้องค์กรยุคใหม่นิยมเปลี่ยนจากการใช้ **Leased Line (วงจรสื่อสารเช่าเฉพาะ)** ระหว่างสาขา มาเป็น **IPsec VPN ผ่านโครงข่ายอินเทอร์เน็ตสาธารณะ**?
A. IPsec VPN มีค่าใช้จ่าย (Cost) ที่ต่ำกว่ามาก และมีความยืดหยุ่นในการขยายจุดเชื่อมต่อ (Scalability) สูงกว่าการลากสายวงจรเช่าทางกายภาพ  
B. Leased Line ไม่สามารถส่งข้อมูลดิจิทัลได้  
C. IPsec VPN ไม่จำเป็นต้องเชื่อมต่ออินเทอร์เน็ต  
D. เพื่อให้พนักงานสามารถเล่นเกมออนไลน์ได้เร็วขึ้น  
**เฉลย: A**  
**คำอธิบาย:** ตามสไลด์ Week 14 เปรียบเทียบตัวเลือกโซลูชัน วงจรเช่าเฉพาะ (Leased Line) มีราคาสูงมากและเชื่อมได้เฉพาะจุดคงที่ ในขณะที่ IPsec VPN ทำงานบนเครือข่ายอินเทอร์เน็ตทั่วไปที่มีอยู่แล้ว จึงช่วยประหยัดงบประมาณและเพิ่มสาขาได้ง่ายดาย
